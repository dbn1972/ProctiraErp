What gets provisioned

  • Isolated PostgreSQL schema with row-level security
  • Dedicated object-storage bucket (ap-south-1)
  • Auth realm with SSO + OTP login policies
  • Message-queue vhost for async workflows
  • Default theme (Odisha Classic) + branding slot
  • District Administrator invite to the admin email
Provisioning is reversible for 72 hoursA new tenant can be torn down without trace within 72 hours. After that, deletion requires a data-retention review.
